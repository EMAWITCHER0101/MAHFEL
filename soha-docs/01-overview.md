# بخش ۱: نمای کلی پروژه محفل

## معرفی پروژه

**محفل (Mahfel)** یک پلتفرم محتوایی فارسی است که تحت عنوان **«سرای هنر و اندیشه»** فعالیت می‌کند. این پلتفرم شامل بخش‌های زیر است:

- **پادکست (صوت)** — مجموعه‌های صوتی با اپیزودهای متعدد
- **ویدیو** — ویدیوهای آپلود شده از Aparat (یوتیوب ایرانی)
- **کتاب** — کتاب‌های مرتبط با پادکست‌ها
- **نشر** — کتاب‌ها و یادداشت‌های منتشر شده توسط نویسندگان
- **محفل (جامعه)** — فروم پیام‌رسانی اجتماعی با پست‌ها و کامنت‌ها
- **هوش مصنوعی** — دستیار AI برای جستجو و تحلیل محتوا
- **پشتیبانی** — سیستم ارسال پیام پشتیبانی

## پشته فناوری

### فرانت‌اند
- **React 18** — کتابخانه اصلی UI
- **TypeScript** — زبان برنامه‌نویسی با نوع‌بندی ایمن
- **Vite** — ابزار build و dev server
- **Tailwind CSS** — فریمورک CSS utility-first
- **Electron** — دسکتاپ (Windows/Mac/Linux)
- **Capacitor** — موبایل (Android/iOS)

### بک‌اند
- **Express.js 4.21** — فریمورک وب Node.js
- **MongoDB** — پایگاه داده NoSQL
- **Mongoose 8** — ODM برای MongoDB
- **JWT** — احراز هویت توکنی
- **Firebase** — ارسال OTP SMS + FCM Push

### سرویس‌های خارجی
- **OpenRouter API** — هوش مصنوعی (Gemini 2.0 Flash)
- **Aparat API** — دریافت اطلاعات ویدیوها
- **SMS.ir** — ارسال پیامک OTP
- **Firebase Cloud Messaging** — push notification اندروید

## سیستم احراز هویت

1. کاربر شماره موبایل را وارد می‌کند
2. سرور OTP را از طریق SMS.ir ارسال می‌کند
3. کاربر کد تأیید را وارد می‌کند
4. سرور توکن JWT صادر می‌کند (انقضا: 7 روز)
5. کلاینت توکن را در localStorage ذخیره می‌کند
6. تمام درخواست‌های بعدی با هدر `Authorization: Bearer <token>` ارسال می‌شوند

## نقش‌های کاربری

| نقش | مجوزها |
|------|--------|
| `user` | پست، کامنت، لایک، کتابخانه، خرید |
| `author` | + ایجاد/ویرایش کتاب و پادکست |
| `admin` | + مدیریت کاربران/پست‌ها/تحلیل‌ها |
| `superadmin` | عبور از تمام بررسی‌های مجوز |

## سیستم real-time

- وب‌سوکت روی پورت 5001 (Go WebSocket server)
- تغییرات MongoDB از طریق Change Stream شنیده می‌شوند
- بک‌اند از طریق HTTP به وب‌سوکت اطلاع‌رسانی می‌کند (`broadcast()`)
- کلاینت از طریق WebSocket به‌روزرسانی‌ها را دریافت می‌کند

## سیستم push notification

- **وب:** Web Push (VAPID) — از طریق Service Worker
- **اندروید:** Firebase Cloud Messaging (FCM) — حتی وقتی اپ بسته است
- **دسکتاپ:** Notification API Chromium

## پلتفرم‌ها

### وب
- SPA با React و Vite
- RTL کامل
- پشتیبانی از حالت تاریک/روشن

### اندروید (Capacitor)
- پخش صدا در پس‌زمینه از طریق AndroidBridge
- Picture-in-Picture برای ویدیو
- Push notification از طریق FCM
- به‌روزرسانی خودکار APK

### دسکتاپ (Electron)
- پنجره مستقل
- اعلان‌های سیستم
- به‌روزرسانی خودکار از GitHub Releases

### iOS
- WebView با Safari
- پشتیبانی محدود از پخش پس‌زمینه
